# Довідник — випуски

Тут лише готові файли програми, без коду.

**Встановити:** відкрийте [останній випуск](https://github.com/alonso85/dovidnyk-releases/releases/latest) і завантажте `dovidnyk-setup-<версія>.exe`. Права адміністратора не потрібні.

Під час першого встановлення Windows SmartScreen може показати попередження: «Докладніше» → «Все одно запустити».

Далі програма оновлюється сама: нова версія завантажується у фоні й встановлюється при закритті.

`dovidnyk-portable-<версія>.exe` — версія без встановлення для разових випадків; сама не оновлюється.
